# Mini Chef Bebé

Aplicación web estática para explorar recetas sencillas y organizar ideas de comidas para la alimentación complementaria. Los datos de favoritos, planificación y lista de compras se guardan localmente en el navegador.

## Publicar en GitHub Pages
1. Descomprimí `mini-chef-bebe-github.zip`.
2. Creá un repositorio en GitHub y subí **el contenido de la carpeta `mini-chef-bebe`**.
3. Verificá que `index.html` quede directamente en la raíz del repositorio (no dentro de otra carpeta).
4. En GitHub abrí **Settings → Pages → Deploy from a branch → main → /(root)** y guardá.
5. Esperá a que GitHub Pages publique el sitio y abrí el enlace que te indique.

## Agregar al celular
- **iPhone:** abrí el enlace con Safari, tocá Compartir y elegí “Agregar a pantalla de inicio”.
- **Android:** abrí el enlace en el navegador y usá “Instalar aplicación” o “Agregar a pantalla de inicio”, si aparece.

## Importante
La app ofrece ideas generales, no asesoramiento médico ni nutricional personalizado. Confirmá con el pediatra el momento de inicio de la alimentación complementaria y la adecuación de alimentos, alérgenos y texturas. El bebé debe comer sentado, erguido y bajo supervisión directa de un adulto. No ofrecer miel antes de los 12 meses. La app no reemplaza leche materna ni fórmula.

Los datos se guardan en el almacenamiento local del navegador del dispositivo. No hay cuenta ni sincronización entre dispositivos.
